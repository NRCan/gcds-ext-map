Couleur de lien

La classe couleur de lien définit la propriété color. Elle détermine la couleur du texte.

Voir les conseils de Système de design GC en matière de couleur pour choisir la bonne couleur de lien pour votre contexte.

Survol

Raccourci de classe CSS Style appliqué 
link-default
 
color: var(--gcds-link-default);
 
link-hover
 
color: var(--gcds-link-hover);
 
link-inherit
 
color: var(--gcds-link-inherit);
 
link-light
 
color: var(--gcds-link-light);

Exemples

Couleur par défaut
link-default

Ce lien utilise la couleur de lien par défaut.
<a href="#" class="link-default">
  Ce lien utilise la couleur de lien par défaut.
</a>

Lien pointé
link-hover

Ce lien utilise la couleur de lien pointé en état de survol.
<a href="#" class="link-hover">
  Ce lien utilise la couleur de lien pointé en état de survol.
</a>

Hériter
link-inherit

Ce lien hérite sa couleur de l’élément parent.
<div style="color: var(--gcds-color-red-700);">
  <a href="#" class="link-inherit">
    Ce lien hérite sa couleur de l’élément parent.
  </a>
</div>

Clair
link-light

Ce lien utilise la couleur de lien clair.
<a href="#" class="link-light">
  Ce lien utilise la couleur de lien clair.
</a>

Style conditionnel Appliquer ces styles à des tailles d’écran précises Utilisez un préfixe de mise en page réactive pour appliquer cette classe uniquement à une taille d’écran précise. Voici les points d’arrêt possibles :

  • xs: > 480px
  • sm: > 640px
  • md: > 768px
  • lg: > 1024px
  • xl: > 1280px
  
<div class="xs:link-hover ...">
  ...
</div>

En savoir plus sur le préfixe de mise en page réactive.

Appliquer ces styles à des états spécifiques Utilisez un préfixe d’état pour appliquer cette classe uniquement à un état d’interaction spécifié. Voici les états possibles :

  • hover
  • focus
  
<div class="hover:link-hover ...">
  ...
</div>
