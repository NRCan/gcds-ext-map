Visibilité

La classe visibilité définit la propriété visibility. Elle affiche ou masque un élément sans affecter la mise en page ou le flux du document.

Survol

Raccourci de classe CSS Style appliqué 
visibility-hidden
 
visibility: hidden;
 
visibility-visible
 
visibility: visible;
 
visibility-sr-only
 
clip-path: inset(100%);
clip: rect(1px, 1px, 1px, 1px);
height: 1px;
overflow: hidden;
position: absolute;
white-space: nowrap;
width: 1px;

Exemples

Masqué
visibility-hidden

Cet élément est masqué. Il ne peut pas être la cible de saisie, mais maintient sa position dans le document, influant sur la mise en page des autres éléments.

1

2

3

<div class="d-flex gap-300">
  <p>1</p>
  <p class="visibility-hidden">2</p>
  <p>3</p>
</div>

Visible
visibility-visible

Cet élément est visible. Cette classe peut s’appliquer à des éléments masqués à différentes tailles d’écran.

1

2

3

<div class="d-flex gap-300">
  <p>1</p>
  <p class="visibility-visible">2</p>
  <p>3</p>
</div>

Masquage accessible
visibility-sr-only

Cet élément est uniquement visible pour les technologies d’assistance.

1

2

3

<div class="d-flex gap-300">
  <p>1</p>
  <p class="visibility-sr-only">2</p>
  <p>3</p>
</div>

Style conditionnel Appliquer ces styles à des tailles d’écran précises Utilisez un préfixe de mise en page réactive pour appliquer cette classe uniquement à une taille d’écran précise. Voici les points d’arrêt possibles :

  • xs: > 480px
  • sm: > 640px
  • md: > 768px
  • lg: > 1024px
  • xl: > 1280px
  
<div class="xs:visibility-hidden ...">
  ...
</div>

En savoir plus sur le préfixe de mise en page réactive.

Appliquer ces styles à des états spécifiques Utilisez un préfixe d’état pour appliquer cette classe uniquement à un état d’interaction spécifié. Voici les états possibles :

  • hover
  • focus
  
<div class="hover:visibility-hidden ...">
  ...
</div>
