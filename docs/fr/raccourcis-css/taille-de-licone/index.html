Taille de l'icône

La classe taille de l'icône définit les propriétés font-size et line-height des icônes. Elle détermine la taille de gcds-icons.

Survol

Raccourci de classe CSS Style appliqué

font-size: var(--gcds-font-sizes-h1);
line-height: var(--gcds-line-heights-h1);

Style conditionnel Appliquer ces styles à des tailles d’écran précises Utilisez un préfixe de mise en page réactive pour appliquer cette classe uniquement à une taille d’écran précise. Voici les points d’arrêt possibles :

  • xs: > 480px
  • sm: > 640px
  • md: > 768px
  • lg: > 1024px
  • xl: > 1280px
  
<div class="xs:icon-text ...">
  ...
</div>
