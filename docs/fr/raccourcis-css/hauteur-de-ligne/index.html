Hauteur de ligne

La classe hauteur de ligne définit la propriété line-height. Elle détermine l'espacement vertical entre les lignes de texte.

Dans la plupart des cas, il n’est pas nécessaire d'utiliser cette classe. Par défaut, le style du corps du texte et des éléments de titre correspondent à ceux de Système de design GC. Utilisez des balises HTML sémantiques, comme h1 et h2 lorsque possible..
