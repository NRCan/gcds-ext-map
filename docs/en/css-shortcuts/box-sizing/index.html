Box sizing

The box sizing class sets the box-sizing property. It specifies if the height and width of an element includes borders and padding.

Overview

CSS Shortcut class Applied style 
box-border
 
box-sizing: border-box;
 
box-content
 
box-sizing: content-box;

Examples

Border
box-border

The size of this element includes the content, border, and padding.

<p class="box-border">
  The size of this element includes the content, border, and padding.
</p>

Content
box-content

The size of this element includes the content only.

<p class="box-content">
  The size of this element includes the content only.
</p>

Conditional styling Apply this style to specific screen sizes Use a responsive layout prefix to apply this class only to a specified screen size. The available breakpoints are:

  • xs: > 480px
  • sm: > 640px
  • md: > 768px
  • lg: > 1024px
  • xl: > 1280px
  
<div class="xs:box-border ...">
  ...
</div>
