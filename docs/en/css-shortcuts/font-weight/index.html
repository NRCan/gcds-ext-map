Font weight

The font weight class sets the font-weight property. It controls how bold text is.

View GCDS typography guidance to choose the right font weight for your context.

Overview

CSS Shortcut class Applied style 
font-regular
 
font-weight: var(--gcds-font-weights-regular);
 
font-light
 
font-weight: var(--gcds-font-weights-light);
 
font-medium
 
font-weight: var(--gcds-font-weights-medium);
 
font-semibold
 
font-weight: var(--gcds-font-weights-semibold);
 
font-bold
 
font-weight: var(--gcds-font-weights-bold);

<p class="font-regular">

Conditional styling Apply this style to specific screen sizes Use a responsive layout prefix to apply this class only to a specified screen size. The available breakpoints are:

  • xs: > 480px
  • sm: > 640px
  • md: > 768px
  • lg: > 1024px
  • xl: > 1280px
  
<div class="xs:font-medium ...">
  ...
</div>

Learn more about the responsive layout prefix.

Apply this style to specific states Use a state prefix to apply this class only to a specified interaction state. The available states are:

  • hover
  • focus
  
<div class="hover:font-medium ...">
  ...
</div>

Learn more about the state prefix.
