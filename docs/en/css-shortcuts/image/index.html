Image

The image class sets the width or max-width properties of an image. It controls how big the image is.

Overview

CSS Shortcut class Applied style 
img-full
 
width: 100%;
 
img-responsive
 
max-width: 100%;

Examples

Full
img-full

</figure>

Conditional styling Apply this style to specific screen sizes Use a responsive layout prefix to apply this class only to a specified screen size. The available breakpoints are:

  • xs: > 480px
  • sm: > 640px
  • md: > 768px
  • lg: > 1024px
  • xl: > 1280px
  
<div class="xs:img-responsive ...">
  ...
</div>
